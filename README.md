These codes and data were developed when we are testing the snow modeling method for the two study areas (CLPX and HV). They are not for automatic run and commercial applications. Please contact Yu Zhang (yu.zhang@NRCan-RNCan.gc.ca) for more information.

The following folders are C++ codes developed using Microsoft Visual Studio Professional C++ 2022 (64-bit), version 17.14.38.
Generating_Input_Files: code for generating input files for ensemble simulations.

Code_for_processing_model_output: code for processing model outputs, including combining the output files together, producing lookup database files.
Thecode_NEST_Snow_Console: code of NEST model for simulating snow dynamics.
Code_Call_exe_File_sedge: code to run multiple batches of NEST for sedge/grass land. 
Code_Call_exe_File_Shrub: code to run multiple batches of NEST for shrub land. 
Code_for_Mapping_CLPX: code for mapping Fsnow and other snow conditions for the CLPX study area.
Code_for_Mapping_HV: code for mapping Fsnow and other snow conditions for the HV study area.

The following two folders contain snow disappearance dates and uncertainties derived from satellite imagery from 2019 to 2025 for the CLPX and HV study areas, respectively. The layers are in raw data format. 

CLPX_SnowEndB_Layers 
HV_SnowEndB_Layers
